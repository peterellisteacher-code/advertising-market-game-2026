# Release Update Refresh Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Refresh open game tabs exactly once after a different, fully cached web release activates.

**Architecture:** Keep update authority in the generated service worker so an already stale page does not need new page JavaScript. Bind a worker-policy revision into the cache identity, detect older release caches during activation, delete them, then re-navigate currently controlled window clients while isolating individual navigation failures.

**Tech Stack:** Node.js 22, JavaScript service worker generated by `scripts/build-web.mjs`, Node test runner, pnpm 11, Netlify.

## Global Constraints

- Installation must verify and cache every core asset before `skipWaiting()`.
- Do not refresh on ordinary visits, first installation, unchanged update checks, or failed installation.
- Preserve current paths and query strings during update navigation.
- Keep `/api/*`, `/.release/*`, worker and manifest requests outside the service-worker cache.
- Preserve network-first document navigation with cached `/index.html` only as the offline fallback.
- Work only in `C:\tmp\admarket-release-refresh-20260803`; do not modify either dirty Advertising worktree.
- Use `corepack pnpm`; do not launch native Godot or mutate Supabase.

- [ ] **Step 3: Implement the minimal generated-worker change**

In `scripts/build-web.mjs`, define the policy revision and include it in the cache hash:

```js
const SERVICE_WORKER_POLICY_REVISION = "release-refresh-v1";

const cacheVersion = createHash("sha256")
  .update(JSON.stringify({
    assets: assetRecords,
    workerPolicyRevision: SERVICE_WORKER_POLICY_REVISION
  }))
  .digest("hex")
  .slice(0, 24);
```

Replace the generated activate body with:

```js
const names = await caches.keys();
const staleReleaseNames = names.filter(
  (name) => name.startsWith(CACHE_PREFIX) && name !== CACHE_NAME
);
await Promise.all(staleReleaseNames.map((name) => caches.delete(name)));
if (staleReleaseNames.length === 0) return;
const windowClients = await self.clients.matchAll({ type: "window" });
await Promise.allSettled(
  windowClients.map((client) => client.navigate(client.url))
);
```

Do not add `clients.claim()` and do not change the fetch handler.
